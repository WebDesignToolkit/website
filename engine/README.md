# WebDesignToolkit Web Design Engine preview snapshot

These files are a **review-only mirror** of the canonical WebDesignToolkit/web-design-engine feature branch feat/engine-v0-1. The engine source repo owns all implementation and tests; edit and review there, then run tools/sync-portal.mjs from the engine repo to refresh this snapshot. Do not use GitHub Actions, remote CDNs or autonomous publishing.

Static preview: /engine/. Source: https://github.com/WebDesignToolkit/web-design-engine

Data entered in the engine remains in the user's browser; the optional exported ZIP stays local unless explicitly downloaded. No server-side client storage, bookings or emails.

## Live v0.3 preview

The `/engine/` version was promoted from `/engine-lab/` after an independent live-browser check of the visual template cards, category-dependent page preview and artwork selectors. The canonical editable source remains `WebDesignToolkit/web-design-engine` on its draft feature branch. Contact and booking forms stay disabled; the client-photo option embeds the supplied file locally without a server upload.
